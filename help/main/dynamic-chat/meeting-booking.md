# 讓您的人員預約與您的銷售團隊開會

使用Dynamic Chat加速[!DNL target]帳戶潛在客戶的銷售連線。 透過[Admin Console](https://adminconsole.adobe.com/)將您的銷售代理程式新增為使用者，讓訪客能夠預約與各種銷售代表的會議，而且每個代理程式應該連線自己的行事曆。
